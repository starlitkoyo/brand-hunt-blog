# サンプル画像 生成プロンプト集（残り15枚）

作成 2026-08-07 ／ 対象＝`public/images/mock/` の `.svg` 15枚を実写WebPに差し替える

> **【2026-08-07 完了】15枚すべて差し替え済み。** `.svg` は全削除、`catalog.ts` の参照も `.webp` に更新、ビルド確認済み。
> これでモック画像20枚（hero＋カテゴリ4＋商品15）が全部実写WebPになった。以降は再生成が必要な時だけ下のプロンプトを使う。

## 使い方

- 各プロンプトは**単体で完結**している（共通スタイルとNGを毎回含めてある）。1枚ずつそのまま貼れる。
- 生成後は `.webp` に変換し、**同名で置き換える**（拡張子だけ `.svg` → `.webp`）。参照先の `data/mock/catalog.ts` の拡張子も直す。
- 実在ブランドは登場しない。このサイトのサンプル商品はすべて架空ブランド（Atelier Nove / Maison Lueur / Neri Beauty / Calma Objects / Studio Aube）なので、**ロゴ・刻印は一切入れない**。

## 書き出しサイズ

| 用途 | ファイル | 比率 | 推奨px |

| カテゴリ（先頭2枚） | `cat-fashion` / `cat-beauty` | 16:10 | 1600×1000 |
| カテゴリ（後半2枚） | `cat-home` / `cat-life-tech` | 3:4 | 900×1200 |
| 商品（11枚） | `product-*` | 4:5 | 1000×1250 |

> 商品画像は一覧では 4:5、特集枠では 16:11 に中央トリミングされる。**被写体は中央に置き、上下に余白を残す。**
